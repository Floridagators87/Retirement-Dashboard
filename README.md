# Retirement HQ

A mobile-friendly retirement and net-worth dashboard designed for GitHub Pages.

## Privacy
Financial values are stored only in your browser's local storage. They are not saved in this repository or uploaded to GitHub.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your `retirement-dashboard` repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Your site should appear at `https://floridagators87.github.io/retirement-dashboard/`.

## iPhone installation
Open the site in Safari, tap **Share**, choose **Add to Home Screen**, and tap **Add**.
